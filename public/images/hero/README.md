# Hero Fotoğrafı (Opsiyonel)

Mevcut hero tasarımı **fotoğrafsız da mükemmel çalışıyor** — sadece büyük tipografi ve hafif gradient arka planı var.

İleride bir hero fotoğrafı eklemek istersen:
- Dosya: `hero.jpg` olarak bu klasöre yükle
- Boyut: 2400x1600 px (3:2 aspect ratio)
- Maks. dosya boyutu: 500KB (optimize et)
- `index.html`'de `.hero` class'ına `background-image` ekle
