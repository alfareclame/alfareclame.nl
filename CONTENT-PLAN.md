> **horeca** (spearhead), **juridisch** (parallel), en **accountant/beauty/retail/bouw** (cluster-coverage).
> Horizon: 9–12 maanden. Doel: organische top-10 rankings voor sector-specifieke AI-zoektermen.

---

## Strategische principes

### Hub-and-spoke architectuur
Drie pillar-pagina's vormen de hubs. Elk pillar heeft eigen cluster-artikelen die terugverwijzen naar de pillar. Google ziet dit als "topic authority" en rankt de hele cluster hoger.

```
                 ┌─ AI voor MKB (hoofd-pillar)
                 │
    ┌────────────┼────────────┐
    │            │            │
  Horeca      Juridisch    Accountant
  pillar       pillar       pillar
    │            │            │
  10 clusters  7 clusters   4 clusters
```

### Intent-mapping
Elk artikel wordt geschreven voor één van drie zoekintenties:
- **Informational** (65%): leren, begrijpen — brede pillars
- **Commercial investigation** (25%): vergelijken, overwegen — cluster-middenveld
- **Transactional** (10%): kopen, starten — specifieke use cases

### Contentlengte per type
- Pillar: 2000–3000 woorden
- Cluster: 1200–2000 woorden
- Specifiek use-case: 800–1500 woorden

### E-E-A-T signals in elk artikel
- **Experience**: concrete voorbeelden uit de praktijk, niet generieke AI-waffle
- **Expertise**: BSc Computer Engineer als auteur — technische diepgang waar relevant
- **Authoritativeness**: bron-links naar Nederlandse autoriteiten (CBS, AP, NLAIC)
- **Trustworthiness**: eerlijk over wat werkt én niet, prijsranges, valkuilen

- **Organisch verkeer** per artikel (Google Search Console)

## Promotiekanalen per artikel

Bij elke publicatie, deze checklist uitvoeren:

1. **Google Search Console** — nieuwe URL submit via URL Inspection
2. **LinkedIn post** — persoonlijke pagina, met native tekst (geen "nieuwe blog!" hype)
3. **Relevante LinkedIn groups** — vakspecifieke groepen (Horeca Nederland, etc.)
4. **Reddit** — `/r/thenetherlands`, `/r/Nederlands`, sector-subreddits waar relevant
5. **Hacker News** — alleen technisch-diepe artikelen
6. **Indie Hackers** — voor ondernemersverhalen
7. **Dutch forums** — higherlevel.nl, zakelijk.nl
8. **E-mail lijst** — bestaande 500 klanten (optioneel per sector)
9. **Twitter/X** — thread van 5-6 tweets met kernpunten
10. **WhatsApp status** — voor directe persoonlijke kring

## Contentkwaliteit-checklist (voor elk artikel)

Voor publicatie, check:

- [ ] Primaire keyword in H1, URL, eerste paragraaf, minstens 2 H2's
- [ ] Meta description 140–160 tekens, met CTA
- [ ] Intro < 100 woorden, direct naar value
- [ ] Minimaal 5 H2's voor scanbaarheid
- [ ] Lijsten en tabellen waar mogelijk
- [ ] 3+ concrete voorbeelden (geen "bedrijf X had meer sales")
- [ ] Prijsranges waar relevant (transparantie)
- [ ] Eerlijke contra-opinie (wat werkt NIET)
- [ ] FAQ sectie onderaan (3–5 vragen)
- [ ] Internal links (minimaal 3)
- [ ] External links naar autoriteiten (CBS, AP, NLAIC, etc.)
- [ ] Schema.org Article + FAQPage markup
- [ ] Alt-tekst op alle afbeeldingen
- [ ] Afbeeldingen < 500 KB, moderne formats
- [ ] Mobile check (echt op telefoon)
- [ ] Inline CTA naar AI Readiness Check
- [ ] Gerelateerde artikelen onderaan

## Keyword research bronnen (gratis)

- Google Keyword Planner (gratis met Ads account)
- Google autocomplete (`AI voor ___`, laat de alfabet door)
- AnswerThePublic (3 gratis zoekopdrachten per dag)
- Ubersuggest (3 per dag gratis)
- "People also ask" in Google SERPs
- Reddit search binnen Dutch subreddits
- Google Trends (voor seizoenspatronen)

Elk artikel krijgt 1 primaire keyword + 3–5 secondaire keywords geïdentificeerd via deze tools voor het schrijven begint.
